# Reference Audio

Add a 5-10 second recording, then run `convert_audio_assets` in MATLAB.
M4A, MP3, FLAC, OGG, OPUS, AIFF, AU, and MP4 inputs are detected.
The source is preserved and the same-name WAV is created without overwrite.
`reference.wav` is preferred; otherwise the demo uses the first WAV alphabetically.
The demo converts stereo input to mono. Do not commit large recordings.
